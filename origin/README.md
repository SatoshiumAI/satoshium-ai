# Satoshium Origin Timeline

**Directory:** `/origin/`  
**Public page:** `index.html`  
**Status:** Active historical and conceptual timeline page

## Purpose

The `/origin/` directory preserves a public narrative of Satoshium’s conceptual and developmental origins.

Its `index.html` presents a phase-based timeline beginning with the April 2025 concept period and continuing through the emergence of the public Satoshium platform in 2026.

This README documents the repository role of the directory. It does not reinterpret the historical narrative or convert earlier development language into current Suite architecture.

## Public Page Relationship

`index.html` is the primary public representation of this directory.

The page currently records the following phases:

- **Phase 0 — Concept Layer (April 2025)**
- **Phase 1 — Foundation & Creation (May–June 2025)**
- **Phase 2 — Utility and Modularity (June–October 2025)**
- **Phase 3 — Simulation and Certification Foundations (Late 2025)**
- **Phase 4 — Public Platform Emergence (February 2026)**
- **Continuing Development**

These phases are historical descriptions of how Satoshium developed and should be read in that context.

## Historical Discipline

The Origin Timeline includes terminology and architectural descriptions from earlier stages of Satoshium’s development, including references to:

- governance structures;
- internal agent architecture;
- protocol-oriented decentralized intelligence;
- simulation environments;
- certification-oriented reasoning systems;
- Aegis as an early operational subsystem;
- Atlas and Aegis appearing within the emerging public platform;
- the broader “Satoshium Universe” framing.

These descriptions should not be silently rewritten merely because later Satoshium architecture became more precise.

Where later Suite institutions, authority boundaries, or canonical objects differ from these earlier descriptions, the timeline should preserve the historical development record unless a statement is factually incorrect about the period it describes.

## Relationship to Current Satoshium Architecture

This page is historical and descriptive.

It does not define current institutional responsibilities for Atlas, Navigator, Certifier, Registry, Chronicle, Anchor, Beacon, Attestor, or any other later Satoshium surface.

Likewise, its references to Aegis reflect the historical development narrative and should not be interpreted as changing Aegis’s present status or relationship to the formal Suite.

Current-state architecture belongs in current institutional documentation, not in retroactive rewriting of the origin record.

## Maintenance

Repository maintenance for `/origin/` should:

- preserve historically accurate phase descriptions;
- distinguish historical terminology from current terminology;
- avoid rewriting earlier development stages to match later architecture;
- correct factual errors only where the historical record supports correction;
- keep the public timeline understandable to present-day readers;
- avoid using this README as a vehicle for Suite redesign.

README reconciliation documents the history and repository state that exist. It does not redesign them.
